# Карьера в ADM GLOBAL

Русскоязычный карьерный сайт со списком вакансий компаний группы на hh.uz: ROODELL, FINCOM, ADM STAMPING и ADMC DASAN. Список работодателей задаётся в `EMPLOYERS` в scripts/update-jobs.py — чтобы добавить компанию, допишите её id с hh.uz. Отклики обрабатывает hh.uz. Информация о группе и изображения получены с [официального сайта ADM GLOBAL](https://adm.uz/ru/).

Для локального просмотра откройте index.html. Зависимости для работы сайта устанавливать не требуется.

## GitHub Pages

Загрузите проект в ветку main. В Settings → Pages выберите источником GitHub Actions и запустите Publish careers site из вкладки Actions. Workflow также публикует изменения в main и ежедневно запрашивает вакансии заново. Для привязки career.adm.uz подтвердите домен в GitHub Pages и настройте его DNS у администратора adm.uz.

Для ручного обновления выполните `python3 scripts/update-jobs.py`. Скрипт сохраняет проверенную выборку и дату в jobs-data.js. Если источник недоступен, при сборке используется снимок из репозитория. Команда `sh scripts/build.sh` собирает статические файлы в dist.

## Возможности сайта

- **Языки RU / UZ.** Русский текст лежит в index.html, узбекский — в `i18n.js` (словарь `UZ` и блок `JS.uz`). Элементы с атрибутом `data-i18n` переводятся автоматически. Язык запоминается в браузере и передаётся в ссылке: `?lang=uz`.
- **Ссылки на подборки.** Фильтры сохраняются в адресе: `?dir=leasing&city=tashkent&q=менеджер`. Направления: `production`, `sales`, `marketing`, `it`, `leasing`, `office`. Кнопка «Ссылка на подборку» копирует текущий адрес.
- **Зарплата и метка «Новая».** Берутся из hh.uz при ежедневном обновлении (`salary`, `published` в jobs-data.js). «Новая» — вакансии, опубликованные за последние 3 дня.
- **Превью ссылки.** Картинка `assets/og-image.jpg` и мета-теги `og:*` в index.html. При переезде на другой домен (например, career.adm.uz) замените адрес в `og:url`, `og:image` и `canonical`.
- **Кэш.** После изменения CSS или JS увеличьте номер `?v=` у подключённых файлов в index.html, чтобы браузеры сразу загрузили новую версию.
- Шрифт Onest хранится в `assets/fonts` (лицензия SIL OFL).
